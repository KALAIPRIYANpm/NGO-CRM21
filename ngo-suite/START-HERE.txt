NGO SUITE - HOW TO START AND SIGN IN
====================================

1. Unzip this file into a NEW folder (do not unzip over an old copy).
   Close any old NGO Suite black windows first.

2. Double-click  START-WINDOWS.bat
   (Mac/Linux: open a terminal in this folder and run:  python3 run.py --port 8020)
   Keep the black window open while you use the software.

3. Open your browser and go to:   http://127.0.0.1:8020

4. Sign in:
      Username: admin        Password: ChangeMe123
   Other demo users (same password ChangeMe123):
      accounts  (accounts and fundraising)
      field     (field work)
      viewer    (view only)

   This folder already contains sample data for "Seva Sankalp Trust".
   After you sign in, open Admin > Branding & setup to put your own name and logo. Look for "Communicate > Broadcast" and "Automations" in the left menu to check this is the new version.
